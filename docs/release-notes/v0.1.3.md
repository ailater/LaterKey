# LaterKey v0.1.3

## 新功能

- **任务管理器**：物理 Ctrl+Alt+Del 或 Ctrl+Esc 呼出 macOS「强制退出应用程序」窗口（走 System Events 特权注入，WindowServer 不认用户态合成的该热键）
- **Win+V 剪贴板历史**：文本与图片（含截图）都记录，面板支持搜索、↑↓/鼠标选择贴回、缩略图、清空；再按 Win+V 或 Esc 关闭。密码管理器标记内容与安全输入期间不采集；历史仅存内存
- **登录时自动启动**：设置面板「开机自启」分区勾选，下次登录生效；关闭只影响下次登录，当前实例继续运行

## 设置面板改版

- 左侧分区导航 + 右侧连续滚动（VS Code 设置式），滚动自动高亮、点击瞬时跳转
- 中英文统一由系统 CJK 字体渲染，根治混排基线错位；键帽符号在面板内改用文字
- 托盘菜单勾选与面板开关实时同步；总开关移到左栏常驻

## 修复

- 关闭开机自启不再误杀当前进程（原先 bootout 会连带终止自己）
- 托盘菜单不再残留旧勾选状态
- 多处界面方框（⌫ ⌃ 等缺字形）与按钮样式不统一问题
