# LaterKey v0.1.4

## 新功能

- **全局唤出设置面板**：任意应用里按 **Ctrl+Alt+K**，设置窗口立即显示并聚焦；可在按键映射或托盘菜单中开关
- **隐藏菜单栏图标**：设置面板「关于」分区新增开关；隐藏后用 Ctrl+Alt+K 唤出设置即可恢复

## 行为修正

- **终端里 Ctrl+C/V 也是复制粘贴**：移除旧的终端豁免，与全局双向互换一致——Ctrl+C 复制（⌘C）、Win+C 中断（⌃C），readline 控制键对应 Win+字母
- **关闭剪贴板面板后焦点还给原应用**：Esc / 再按 Win+V 关闭面板不再把设置窗口留在前台

## 健壮性

- 合成事件改用 Cf（RAII）管理生命周期，消除手动释放风险
- **退出时补发被改写修饰键的抬起**：Ctrl 按住期间退出不再导致系统卡在 ⌘ 按下（卡键）
- release 流水线 bump-cask job 已就绪（配置 AILATER_TAP_TOKEN 后自动更新 tap）
