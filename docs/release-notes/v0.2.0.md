# LaterKey v0.2.0

## 快捷键速览（键指如飞）

- **长按物理 Ctrl 2 秒**呼出速览浮窗（期间不敲别的键、不点鼠标；托盘菜单也可手动呼出）：左栏是当前应用的全部菜单快捷键（经辅助功能 API 读取），右栏是系统快捷键（调度中心 / 聚焦 / 输入法 / 屏幕快照等）
- **「物理键 / Mac 原生」双口径**：按你当前的互换开关换算，直接告诉你该按什么；Mac 口径用键帽符号显示（运行时从系统苹方提取字体，键帽符号走 Apple Symbols 回退）
- **点击浮窗里的行**回到原应用并执行该快捷键；Esc、点击外部、右上角 × 关闭；内容放不下时可滚动，超长行悬停显示全文
- 视口与排版按参考图固定坐标一比一复刻（1017×849）：左栏当前应用区、右侧系统双列流式布局，组标题与行距全部常量化
- 字号可在 `config.toml` 的 `[cheatsheet]` 配置（title_size / group_size / key_size / name_size）
- 系统级热键（显示桌面 / 调度中心等 Dock 负责的一类）点击执行走 System Events 特权注入
