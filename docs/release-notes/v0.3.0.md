# LaterKey v0.3.0

## 访达里 Ctrl+/ 在当前文件夹打开终端

- **在此处打开终端**：前台是访达时按物理 Ctrl+/，取当前 Finder 窗口所在文件夹，直接把终端落在那个目录；没有 Finder 窗口时落主目录。拉起终端的子进程全程走独立线程，不占拦截主循环
- **终端可选（默认自动）**：`auto` = 装了 LaterTerm 用 LaterTerm（`open -na LaterTerm --args <目录>`，新实例落目录），否则系统自带 Terminal；拉起失败自动回退 Terminal.app
- **设置面板下拉选择**：「按应用生效」分区开关下方新增终端下拉（自动 + 系统里检测到的已装终端：LaterTerm / Terminal / iTerm2 / Ghostty / WezTerm / Alacritty / kitty，经 Launch Services 安装登记表检测），选择持久化到 toggles.toml
- **config.toml 的 `[terminal]`**：`app` 支持全部预设、带点号 bundle id、应用名；`command` 自定义命令模板优先于 app，`{path}` 替换为访达当前文件夹（单引号转义后经 sh 执行），可接入 Warp 等任意终端
- 开关进托盘菜单与设置面板；修饰键精确匹配——多按 Shift 不触发，其他应用里 Ctrl+/ 保持 ⌘/ 原义
