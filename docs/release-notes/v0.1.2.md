# LaterKey v0.1.2

## 新功能

- **Ctrl+鼠标左键 → ⌘+点击**：VS Code / TRAE / Zed 里 Ctrl+点击跳转到定义，浏览器 Ctrl+点击新标签打开，访达 Ctrl+点击多选。按下、抬起、拖拽事件一致换算（v0.1.1 之前只改按下会导致手势不完整）。

## 设置面板重设计

- Tokyo Night 暗色主题、卡片分组、iOS 风格动画开关；
- 内容可滚动，窗口缩小也能用；
- **权限卡片**：辅助功能与监听事件（ListenEvent）各自的状态、跳转系统设置的按钮、「重新检测」一键复检；配置目录入口也在这里；
- 中文字体加载系统苹方，检测结果的 √/× 避免了字体缺字。

## 其他

- README 重写：brew 安装、软件截图、完整的 Windows 习惯 ↔ Mac 效果对照表；
- 修复「查看配置目录」在目录不存在时报错。

## 升级

```bash
brew update && brew upgrade --cask laterkey
```

辅助功能授权升级后保持有效。
