# LaterKey v0.1.1

修复常驻运行的三个问题（v0.1.0 上 `laterkey install` 后「没效果」的根因）。

## 修复

- **权限门槛用错**：启动检查误用 `CGPreflightListenEventAccess`（macOS 15+ 独立的 ListenEvent 权限），辅助功能已授权、ListenEvent 被拒时误判「没有辅助功能权限」退出。主动拦截真正需要的是辅助功能（AXIsProcessTrusted），已改正；授权弹窗也改走 AX prompt，不再产生 ListenEvent 的拒绝记录。
- **`laterkey install` 的 launchctl 语法**：bootout 第二参数必须是完整 service path，否则旧服务卸不掉、再次 bootstrap 报 `Bootstrap failed: 5`。
- **常驻目标指向 .app 本体**：不再复制裸二进制副本（副本脱离 TCC 授权身份）；裸启动即菜单栏托盘，不再是纯 CLI 常驻。
- `doctor` 现在分开显示「辅助功能」与「ListenEvent（仅诊断）」两项权限，不再混淆。

## 升级

```bash
brew update && brew upgrade --cask laterkey
laterkey install   # 重新注册常驻（指向 .app、托盘模式）
```

辅助功能授权在升级后保持有效（同一自签名证书）。
