# LaterKey v0.1.0

首个发布。让 Windows 布局的普通键盘在 macOS 上按 Windows 的习惯工作——纯用户态实现，不装驱动、不依赖 Karabiner。

## 功能

- **物理 Ctrl 当作 ⌘**：Ctrl+C/V/X/Z 复制粘贴等，所有应用生效
- **物理 Win 当作 ⌃**：Win+C = Ctrl+C，终端里的中断/控制键（与上一条同时成立，编辑区与内嵌终端互不干扰）
- **左 Alt+Tab** → ⌘Tab 应用切换器
- **Win+L** 立即锁屏
- **Ctrl+←/→/⌫** 按词跳转/删除；**Ctrl+Space / Win+Space** 切换输入法
- **访达里 F2** 重命名、**浏览器里 F5** 刷新
- **再点一次前台应用的 Dock 图标** → 最小化窗口
- **菜单栏托盘**：逐项开关以上功能；「设置…」面板，改动即时生效

## 安装

```bash
brew install --cask crazykun/ailater/laterkey
```

或下载 dmg 把 LaterKey.app 拖进 /Applications。

**首次使用必须授权**：系统设置 › 隐私与安全性 › 辅助功能 › 添加 LaterKey.app。
